# 🎓 FATEC Diadema - DSM (Projeto 08)

Aplicativo Android desenvolvido em **Java** com múltiplas telas (Activities) para promover o curso superior de **Desenvolvimento de Software Multiplataforma (DSM)** da **FATEC Diadema - Luigi Papaiz**.

## 📱 Estruturas e Telas do App

1. **Tela 1 (Principal):** Apresentação completa do curso (o que se estuda, perfil do profissional e mercado de trabalho), com identidade visual oficial em tons de bordô.
2. **Tela 2 (Vestibular):** Informações detalhadas sobre o processo seletivo, dicas de preparação e links úteis.
3. **Tela 3 (Multimídia):** Player de vídeo institucional (`VideoView`) sincronizado com uma barra de progresso (`SeekBar`) baseada na aula prática de controle multimídia, com botões de **Play, Pause e Stop**.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Java
- **Componentes:** `Activities`, `Intents`, `VideoView`, `SeekBar`, `MaterialCardView`
- **IDE:** Android Studio
